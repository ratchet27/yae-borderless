# You Are Empty: Absolute Edition — полноэкранный режим без рамки

**Русский** · [English](README.en.md)

Мод добавляет в You Are Empty: Absolute Edition полноэкранный режим без рамки
(borderless fullscreen):

- игра не переключает разрешение монитора;
- Alt+Tab работает мгновенно, игра не сворачивается и остаётся видна под
  другими окнами;
- в фоне игра продолжает работать на полной частоте кадров вместо 5 FPS;
- в настройках появляется пункт **Режим экрана**: Оконный, Полный экран или
  Без рамки.

Файлы игры не изменяются: мод — это одна DLL, которую достаточно положить
рядом с игрой и удалить, чтобы вернуть всё как было.

## Установка

1. Скачайте последний архив со страницы
   [Releases](../../releases).
2. Скопируйте `version.dll` и `yae_borderless.ini` в папку с
   `you_are_empty.exe`. В Steam: ПКМ по игре → Управление → Просмотреть
   локальные файлы.
3. Запустите игру. В разделе Настройки → Видео выберите **Режим экрана: Без
   рамки** и разрешение, совпадающее с разрешением рабочего стола.

Linux / Steam Deck (Proton): в параметрах запуска игры укажите
`WINEDLLOVERRIDES="version=n,b" %command%`.

### Удаление

Удалите `version.dll` и `yae_borderless.ini` из папки игры.

## Режимы экрана

| Режим | Что происходит |
|---|---|
| Оконный | Обычное окно, как в оригинале. |
| Полный экран | Оригинальный эксклюзивный полноэкранный режим: при Alt+Tab игра сворачивается. |
| Без рамки | Окно без рамки на весь экран в разрешении рабочего стола. |

Переключение между «Полный экран» и «Без рамки» применяется сразу после
нажатия OK. Переключение в оконный режим и обратно, как и в оригинальной
игре, требует перезапуска.

Режим «Без рамки» работает, только если разрешение игры совпадает с
разрешением рабочего стола. При другом разрешении игра запускается в
эксклюзивном полноэкранном режиме.

## Настройки

Файл `yae_borderless.ini` рядом с игрой. Режим экрана меняется из игры,
остальное — вручную.

| Параметр | Значения | По умолчанию |
|---|---|---|
| `mode` | `borderless` (без рамки), `exclusive` (полный экран) | `borderless` |
| `present` | `dxgi`, `opengl` | `dxgi` |
| `background_fps` | `full` (полная), `throttled` (5 FPS, как в оригинале) | `full` |

`present`:

- `dxgi` — кадры выводятся через DXGI (как в современных играх на DirectX).
  Минимальная задержка, Alt+Tab без мерцания. Оверлей Steam появляется через
  пару секунд после запуска.
- `opengl` — кадры выводит сама игра через OpenGL, окно на 1 пиксель выше
  экрана, чтобы драйвер не считал его эксклюзивным. Чуть больше задержка
  (примерно один кадр), зато максимальная совместимость. Используется
  автоматически, если DXGI недоступен.

## Если что-то не работает

После запуска рядом с игрой появляется `yae_borderless.log` — в нём написано,
что сделал мод. Приложите его к сообщению об ошибке.

- **Ничего не изменилось и лога нет.** DLL не загрузилась: проверьте, что файл
  называется `version.dll` и лежит рядом с `you_are_empty.exe`. В Proton
  нужен параметр запуска из раздела «Установка».
- **Игра всё равно в эксклюзивном режиме.** В логе будет
  `differs from the desktop: exclusive`: разрешение игры не совпадает с
  разрешением рабочего стола.
- **Антивирус удалил `version.dll`.** Эвристика антивирусов иногда реагирует
  на DLL-прокси. Сверьте файл с `SHA256SUMS.txt` из релиза и восстановите его
  из карантина или соберите мод сами.
- **Чёрный экран или проблемы с картинкой.** Укажите `present = opengl` в
  `yae_borderless.ini`.

Проверено на Windows 11 с видеокартой NVIDIA и Steam-версией игры
(обновление от октября 2026 г.). На AMD и Intel мод не проверялся.

## Как это работает

`version.dll` — прокси системной библиотеки: все её функции передаются
настоящей `version.dll`, а при загрузке мод подменяет несколько импортов
модулей игры:

- запрос на смену видеорежима под разрешение рабочего стола считается
  выполненным, а окно игры создаётся без флага «поверх всех окон»;
- пропускается сворачивание окна и пауза 200 мс на кадр, которые движок
  делает при потере фокуса;
- кадры OpenGL копируются в текстуру D3D11 (`WGL_NV_DX_interop2`) и
  выводятся через цепочку обмена DXGI flip model;
- в окно настроек добавляется выпадающий список «Режим экрана», а
  оригинальный флажок «В полный экран» скрыт и управляется списком.

Подробности — в комментариях в `mod/src`.

## Сборка

Нужен `i686-w64-mingw32-gcc` (MinGW-w64).

```
mod/build.sh   # → mod/dist/version.dll, mod/dist/yae_borderless.ini
```
